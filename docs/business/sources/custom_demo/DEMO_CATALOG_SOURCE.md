## 4. 简化业务规则

- 套餐、资源包均指国内使用，不含港澳台和国际业务。
- 套餐变更按已批准项目规则立即生效，立即扣除新套餐全额月费，原套餐不退款。
- 套餐变更后，账户剩余流量和通话分钟重置为新套餐的完整额度；原套餐和此前附加包剩余量不结转。确认问题必须明确告知该条件。
- 套餐退订立即生效、不退款，并将剩余流量和通话分钟置零。
- 流量包和语音包允许重复购买；每次购买独立扣费并增加相应剩余量。
- 增值业务不允许重复开通；已订购时返回 `INVALID_STATE`。
- 余额不足时拒绝交易，不允许负余额。
- 账户状态为 `abnormal` 时禁止写操作并进入 Demo 人工介入。
- 所有写操作继续执行独立下一轮确认、幂等、原子事务和确定性响应规则。

## 5. 最小测试账户

- `demo_user_001`：正常账户、余额充足，用于成功查询和办理。
- `demo_user_002`：正常账户、余额不足，用于拒绝扣费。
- `demo_user_003`：异常账户，用于验证人工介入。

移动标识、余额、Token 和剩余量均为纯合成数据。静态 `DEMO_TOKEN_` 只用于本地公开 Demo 身份模拟，不具备生产凭证安全性。

## 6. 不包含的复杂能力

- 地区、渠道、品牌、合约期和营销资格校验。
- 套外流量和语音计费。
- 月度资源重置、结转和增值业务跨月续费任务。
- 真实支付、真实优惠、真实工单或真实运营商 API。
- 国际漫游、开户、销户、停机保号、宽带移机和身份认证自动办理。
